# Recursos 3D (estilo cartoon low-poly)

Pacotes gratuitos **KayKit** (Kay Lousberg, licença **CC0**: uso livre, inclusive comercial; crédito opcional a www.kaylousberg.com).

| Pacote | Conteúdo |
|---|---|
| Character Pack: Adventurers | 5 personagens (Knight, Barbarian, Mage, Rogue, Rogue_Hooded) com 76 animações cada: Idle, Walking, Running, Cheer, Waving, Sit, Lie, Jump, Interact... |
| City Builder Bits | prédios, casas, carros, árvores, arbustos, bancos, ruas |
| Furniture Bits | móveis para cenas internas |
| Prototype Bits | formas básicas, pisos, paredes |

Para baixar: `bash assets-3d/baixar-kaykit.sh` (são cerca de 185 MB, por isso ficam fora do repositório).

Os modelos estão em formato glTF/GLB e funcionam com Three.js, Remotion (`@remotion/three`) e HyperFrames.
