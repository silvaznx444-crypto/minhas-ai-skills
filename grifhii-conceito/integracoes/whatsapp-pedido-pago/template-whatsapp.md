# Template para aprovação na Meta (categoria: UTILITY / Utilidade)

Nome: `pedido_pago_envio` · Idioma: Português (BR)

Corpo:
> Olá, {{1}}! O pagamento do seu pedido {{2}} na GRIFHII CONCEITO foi confirmado. Vamos te chamar por aqui para confirmar o endereço e os detalhes do envio pelos Correios (ou da retirada na loja). Nunca pedimos dados de cartão nem pagamentos por WhatsApp. Dúvidas? Responda esta mensagem.

Exemplos para aprovação: {{1}} = "Marina", {{2}} = "#1001".

Observações:
- Não incluir valores, CPF, endereço completo ou dados de pagamento na mensagem.
- O texto não pode anunciar cobrança de frete posterior: o frete é cobrado no checkout (ver legal/entrega.html).
